# Concerns

* Following are the concerns which are to be addressed through this project:

1. Missing out on important tasks (especially one with strict deadlines) 
2. High priority tasks are not worked upon first
3. Time allocation doesn't exist (instead is in a "freestyle" manner at the moment)
4. Performing a retrospective analysis is just impossible (due to lack of any logging)
5. Progress cannot be tracked
6. Cannot reallocate time in order to improve efficiency

# Anti concerns

* Kind of like, what this project is not:

1. Cannot magically make you productive
2. Nothing can replace the actual efforts required to finish any task
3. Discipline is not being replaced, while this tool can make you aware of how your time management looks like (whether good or bad), this will again only be applicable if you sincerely log your time
4. At the end of the day, this tool is for convinience only
